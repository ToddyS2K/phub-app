# PHub – Mini App

Pagina della Mini App di Telegram del PHub (portafoglio). Nessun dato personale qui: l'archivio è cifrato in un gist segreto e si decifra nel browser con la chiave che arriva nel frammento # dell'indirizzo.

`demo.txt` contiene solo dati di prova inventati: [apri la demo](https://toddys2k.github.io/phub-app/#demo).
